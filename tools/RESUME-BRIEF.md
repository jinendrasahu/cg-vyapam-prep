# अधूरे "विस्तृत अभ्यास" अध्याय को पूरा करना

पिछला लेखक बीच में रुक गया। आपकी फ़ाइल वैध है पर अधूरी है — questions array के अंत में `    // __MORE__` पंक्ति है।

1. `tools/DEEP-BRIEF.md` और `tools/FORMAT.md` पढ़ें — वही नियम लागू हैं।
2. अपनी फ़ाइल का `title`, `notes` व `extra` पढ़ें — विषय-क्षेत्र वही है। notes/extra अधूरे लगें तो उन्हें पूरा कर सकते हैं (Edit से), पर मौजूदा सही सामग्री न हटाएँ।
3. `node tools/dump.cjs <file>` से अब तक के सारे प्रश्न पढ़ें; किसी को दोहराएँ नहीं। बताए गए "संबंधित अध्याय" के प्रश्न भी देख लें।
4. Edit से `    // __MORE__` को ~40 नए प्रश्न + marker से बदलें; दोहराते रहें जब तक **कुल ≥ 280 प्रश्न** हों और **पूरे अध्याय में ≥ 40% उच्च-स्तरीय** (कथन/सुमेलन/अभिकथन-कारण/कालक्रम/असुमेलित) हों। अंत में marker हटा दें।
5. हर चरण के बाद `node tools/validate.cjs <file>` — ✓ और 0 त्रुटि।
6. केवल अपनी फ़ाइल बदलें। अंतिम रिपोर्ट: validator पंक्ति (पहले → बाद), उच्च-स्तरीय संख्या, छोड़े गए तथ्य (1–2 पंक्ति)।
