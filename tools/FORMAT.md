# अध्याय फ़ाइल का प्रारूप (content authors के लिए)

हर अध्याय एक फ़ाइल है: `data/<subject>/<id>.js` (जैसे `data/gs/gs-01.js`)। फ़ाइल में ठीक एक `BOOK.add({...})` कॉल होती है।

```js
BOOK.add({
  subject: 'gs',            // फ़ोल्डर का नाम: gs | cg | comp | reas | math | hin | eng
  id: 'gs-01',              // फ़ाइल का नाम (बिना .js)
  title: 'भारत का इतिहास एवं स्वतंत्रता आंदोलन',
  notes: `
    <h3>प्राचीन भारत</h3>
    <p>...</p>
    <ul><li>...</li></ul>
    <table><tr><th>वर्ष</th><th>घटना</th></tr><tr><td>1857</td><td>प्रथम स्वतंत्रता संग्राम</td></tr></table>
    <div class="tip">याद रखने की ट्रिक: ...</div>
  `,
  extra: `
    <h3>गहन तथ्य — जो सामान्य पाठक नहीं जानता</h3>
    <ul><li>...</li></ul>
  `,
  questions: [
    { q: 'प्रश्न का पाठ?', o: ['विकल्प A', 'विकल्प B', 'विकल्प C', 'विकल्प D'], a: 2, e: 'संक्षिप्त व्याख्या — सही उत्तर क्यों सही है।' },
  ]
});
```

## नियम
- **भाषा:** सब कुछ हिन्दी (देवनागरी) में। अपवाद: General English के प्रश्न/विकल्प अंग्रेज़ी में, पर `notes`, `extra` और `e` (व्याख्या) हिन्दी में। कम्प्यूटर के तकनीकी शब्द हिन्दी में लिखें और कोष्ठक में अंग्रेज़ी दें, जैसे "केंद्रीय प्रसंस्करण इकाई (CPU)"।
- `notes` और `extra` HTML स्ट्रिंग हैं (backtick template literal)। उनके अंदर backtick (`) या `${` न लिखें। अनुमत टैग: h3, h4, p, ul, ol, li, table, tr, th, td, b, i, br, div class="tip"। 
- `notes` = उस अध्याय की परीक्षा-उपयोगी पूरी पठन-सामग्री (तालिकाएँ, सूचियाँ, तिथियाँ, सूत्र)। `extra` = "गहन तथ्य": वे बारीक तथ्य, अपवाद, तुलना और ट्रिक जो सामान्य किताबों से आगे हैं।
- हर प्रश्न: `q` (स्ट्रिंग), `o` ठीक 4 अलग-अलग विकल्प, `a` = सही विकल्प का index **0 से 3**, `e` = 1–2 पंक्ति की व्याख्या जिसमें सही उत्तर का कारण / अतिरिक्त तथ्य हो।
- सही उत्तर की स्थिति A/B/C/D में लगभग बराबर बाँटें (validator 40% से ऊपर एक स्थिति पर चेतावनी देता है)।
- अध्याय के भीतर कोई प्रश्न दोहराएँ नहीं। "उपरोक्त सभी / इनमें से कोई नहीं" कम से कम प्रयोग करें।
- **शुद्धता सबसे ज़रूरी है।** केवल वही तथ्य लिखें जिनके बारे में आप पूरी तरह आश्वस्त हैं। विवादित/अनिश्चित आँकड़े छोड़ दें। जनगणना के आँकड़े 2011 के हों और "(जनगणना 2011)" लिखें। जो तथ्य समय के साथ बदलते हैं (पदधारी, ज़िलों की संख्या, योजनाएँ) उनमें "(2026 की स्थिति)" या वर्ष लिखें।
- प्रश्नों का स्तर: लगभग 30% आसान, 50% मध्यम, 20% कठिन — CG व्यापम / CGPSC प्रारंभिक के पिछले वर्षों के प्रश्नों जैसा।

## जाँच
हर फ़ाइल लिखने के बाद चलाएँ: `node tools/validate.cjs data/gs/gs-01.js` — सभी त्रुटियाँ ठीक करें (✓ आना चाहिए)।

## जनरेटर फ़ाइल (केवल reas-gen / math-gen)
```js
BOOK.addGenerator({
  subject: 'math', id: 'gen-percent', title: 'प्रतिशत',
  make(R) {           // R.int(a,b), R.pick(arr), R.shuffle(arr), R.rnd(), R.mcq(correct, [w1,w2,w3]) -> {o, a}
    const x = R.int(2, 9) * 10, p = R.pick([10, 20, 25, 50]);
    const ans = x * p / 100;
    const { o, a } = R.mcq(ans + '', [ans + 5 + '', ans * 2 + '', ans - 2 + '']);
    return { q: x + ' का ' + p + '% कितना है?', o, a, e: x + ' × ' + p + '/100 = ' + ans };
  }
});
```
एक फ़ाइल में कई `BOOK.addGenerator` हो सकते हैं। `make` हर बार 4 **अलग** विकल्प लौटाए (गलत विकल्प सही उत्तर के बराबर न हों)।

## दूसरा दौर: मौजूदा अध्याय में प्रश्न जोड़ना
- नए प्रश्न उसी फ़ाइल के `questions` array के **अंत में** जोड़ें (अंतिम `]` से पहले)। मौजूदा प्रश्नों, `notes` या `extra` को न बदलें (जब तक कोई तथ्यात्मक त्रुटि न मिले)।
- पहले `node tools/dump.cjs <file>` से मौजूदा प्रश्न पढ़ें ताकि कोई प्रश्न या तथ्य दोहराया न जाए — एक ही तथ्य को सिर्फ़ शब्द बदलकर दोबारा न पूछें।
- उच्च स्तर के प्रश्न-प्रकार (CGPSC/व्यापम शैली), `q` में `<br>` से पंक्तियाँ तोड़ सकते हैं:
  - **कथन-आधारित:** "निम्नलिखित कथनों पर विचार कीजिए —<br>1. ...<br>2. ...<br>सही कथन है/हैं —" विकल्प: "केवल 1", "केवल 2", "1 और 2 दोनों", "न तो 1 न ही 2"।
  - **सुमेलित कीजिए:** "सूची-I को सूची-II से सुमेलित कीजिए —<br>(A) ... (B) ... (C) ... (D) ...<br>1. ... 2. ... 3. ... 4. ..." विकल्प: "A-2, B-4, C-1, D-3" जैसे कूट (चारों अलग)।
  - **अभिकथन-कारण:** "अभिकथन (A): ...<br>कारण (R): ..." विकल्प: "A और R दोनों सही हैं तथा R, A की सही व्याख्या है" / "A और R दोनों सही हैं परंतु R, A की सही व्याख्या नहीं है" / "A सही है, R गलत है" / "A गलत है, R सही है"।
  - **कालक्रम:** "निम्नलिखित को कालक्रमानुसार व्यवस्थित कीजिए —"।
  - **"कौन-सा युग्म सही सुमेलित नहीं है?"**

## व्याख्या (e) का विस्तृत प्रारूप — गणित व रीजनिंग
`e` में HTML चलता है (`<b>`, `<br>`)। हर प्रश्न का पूरा हल ऐसे लिखें कि कमज़ोर विद्यार्थी भी बिना शिक्षक के समझ ले:
```
<b>हल:</b><br>
चरण 1: (क्या दिया है / किस नियम/सूत्र का प्रयोग — सूत्र लिखें)<br>
चरण 2: (गणना, हर पंक्ति में एक कदम)<br>
चरण 3: ...<br>
अतः उत्तर = <b>...</b><br>
<b>शॉर्टकट:</b> (यदि कोई तेज़ तरीका हो — परीक्षा में समय बचाने के लिए)<br>
<b>ध्यान दें:</b> (सामान्य गलती — कौन-सा गलत विकल्प किस गलती से आता है)
```
- शॉर्टकट और "ध्यान दें" तभी लिखें जब सार्थक हों। आसान प्रश्नों में 2–3 चरण काफ़ी हैं; कठिन प्रश्नों में सभी चरण।
- रीजनिंग में पैटर्न दिखाएँ: जैसे `2 →(+3) 5 →(+5) 10 →(+7) 17`, अक्षरों के स्थान-मान (A=1…Z=26) लिखकर, रक्त संबंध में पीढ़ी-क्रम लिखकर, दिशा में हर मोड़ के बाद की दिशा लिखकर।
- कथन/सुमेलन/अभिकथन-कारण प्रश्नों में हर कथन/युग्म के बारे में एक-एक पंक्ति: सही/गलत और क्यों।
- बदलाव `node tools/patch.cjs <file> <patch.json>` से करें (patch.json = `{"प्रश्न-संख्या": {"e": "..."}}`; प्रश्न-संख्या `tools/dump.cjs` वाली)। JSON में `"` को `\"` लिखें। हर patch के बाद `node tools/validate.cjs <file>` चलाएँ।
